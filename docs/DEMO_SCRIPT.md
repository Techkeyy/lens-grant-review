# Lens demo video — 1–4 minute recording plan

**Status, 27 October 2026:** no final video has been recorded or verified. Do not present this script as the video. The HackOS Submission Requirements call for the actual Lens workflow, a visible Zetaris query, the Meterless Engine feature, and one real request through Meterless Nightshift with its returned result.

## Recording gate

1. Open the owner-controlled Lens environment with the five registered synthetic grant tables reachable in Zetaris. Do not expose the API token, service-role key, Google account details or any real charity records.
2. Import those tables in Lens, run the check, and confirm the visible import manifest has five table counts, source keys, hashes and query request IDs. The selected follow-up must show which Zetaris tables were reread and whether they matched the snapshot.
3. Open the four-hour timesheet question. Show both four-hour draft claims, the original `TS-101` row, and the 8-versus-4 comparison. Save a correction, rerun, and show the changed finding.
4. Show the Meterless World Model record tied to that run: a source ID, finding ID, and the human action after a fresh read. Name the local reference runtime accurately.
5. **Unmet gate:** connect a real Nightshift hotspot, make Lens send a request to `meterless/auto`, and show the returned selected follow-up, model and request ID in the review trace. An adapter test or the free Nightshift web page does not satisfy this gate. This PC has Intel HD Graphics 620; the Windows provider requires a dedicated GPU. Obtain a supported remote hotspot or event-specific access route before recording this claim.

## Three-minute storyline once every gate passes

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:20 | Two invented draft reports and one timesheet | “A small charity is preparing two funder reports. Each looks plausible alone, but both claim the same staff shift.” |
| 0:20–0:45 | Lens owner import; five Zetaris table receipts | “Lens reads the registered reports and evidence from Zetaris and keeps source identities and query receipts.” |
| 0:45–1:20 | Run check; original claims and `TS-101` | “The reports claim eight hours from one timesheet recording four. Lens cites the rows and asks a reviewer which allocation needs attention.” |
| 1:20–1:45 | Nightshift response and selected follow-up | “Nightshift chooses which supported evidence question to inspect next. The model cannot rewrite the source links or arithmetic.” Name the actual returned model and request ID. |
| 1:45–2:15 | Save correction; rerun; new result | “The reviewer changes the saved claim and checks again. The original source remains visible.” |
| 2:15–2:40 | Meterless World Model trace and review reopen | “The source, finding and human action are linked in Meterless’s World Model reference runtime. The review can be reopened.” |
| 2:40–3:00 | Activity gap and supported split | “Ten reported workshops have eight supplied records. That gap stays open. A valid 70/50 split of a $120 receipt is not flagged.” |

End on a real result. Keep the recording between one and four minutes. The live public sample path is useful for judges to try, but its CSV and sample imports are labelled snapshot-only: do not splice it into footage of the separate owner-controlled Zetaris import as if they were one run.
